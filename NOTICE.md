# Origin

The vehicle menu integration was adapted from the user-supplied Task Force Kraken Hunter / Knight Security vehicles module, including its separate IFV, tank, helicopter and VTOL purchase groups. This starter generalizes its namespace, configuration and preview lookup, and removes the dependency on the Kraken Hunter template addon.

Antistasi Ultimate supplies the mission, native vehicle cards, payment, placement and garage systems; CBA supplies event and scheduling APIs. Their code and vehicle assets are supplied by those separately installed projects. This ZIP contains the extension source, a built extension PBO, examples and documentation.
